## Fixes carried in the same commit (each would have failed silently)

1. `app.py` switch-role `back` allowlist now accepts `/archive2608`.
2. `index.html` role picker now sends `?back=/archive2608` — it sent none, so every
   role switch on the archive teleported the user to the new production app.
3. `alpha_preview.html` "Old App" button → "Archive (2608)", admin-gated (the
   archive is admin-only, everyone else would have got a 403).
4. `login_required` and `_gate()` login bounces now return to the page that was
   asked for, not a hard `/`; both guard against a protocol-relative `//` back.
5. `_gate()` tests API-vs-page **before** the sign-in check and returns JSON 401.
   Previously a fetch on an expired session got a 302, `res.json()` threw, and
   `boot()` painted its DEMO seed — synthetic machines on the production board.
6. `boot()` now reloads on 401 instead of falling through to `demoSeed()`.
7. Archive gate checks admin in the user's **claims** (`get_all_roles`), then
   checks the **active role** is admin — an admin on a `field_manager` cookie
   would otherwise get a field_manager page whose every admin call 403s.
8. `ALPHA_OK` flag: if the production blueprint ever fails to import, `/`
   redirects to `/archive2608` and the admin-only gate is dropped, so everyone
   still has a working app. Without this the rollback path was admin-only in
   exactly the situation it exists for.
9. Streamlined app now has a **Sign out** button — the archive carried the only
   one, and this runs on shared driver tablets. All sign-outs land on
   `/signed-out` rather than `/`, which would bounce straight back into AAD.
